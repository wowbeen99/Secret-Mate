# **Secret Mate** 
## **CH.9 최종 프로젝트 - TikTok 인게이지먼트 광고 프로젝트**
#### **랜딩페이지 기획 의도**
- **게이미피케이션:** 가챠(뽑기) 방식의 놀이형 UI를 적용해 호기심을 자극하고 테스트 참여를 유도한다.
- **맞춤형 경험:** '개인 맞춤형 K-캐릭터' 발급으로 여행 취향을 완벽하게 매칭한다.
- **자발적 확산 유도:** 취향 저격 캐릭터로 SNS 결과 공유 및 2차 바이럴을 유도한다.

#### **테스트 구성**
- **이탈률 최소화:** 빠르고 직관적인 참여를 위해 문항 수를 간소화해 진입장벽을 완화한다.
- **관심사 기반 성향 분류:** A(식도락), B(뷰티), C(트렌드) 선택지로 관심사를 세분화했다.
- **가중치 기반 매칭 로직:** 문항별 가중치를 적용해 정교한 결과를 도출한다.
